# G1yrex Support

A Discord ticket bot with:
- Ticket panel
- Support / Staff App / Media App tickets
- Ticket logs
- /open and /close
- /embed send
- /msg send
- /ban

## Setup

1. Install Node.js 20+.
2. Run:
   ```bash
   npm install
   ```
3. Create a `.env` file:
   ```env
   TOKEN=YOUR_DISCORD_BOT_TOKEN
   CLIENT_ID=YOUR_APPLICATION_ID
   GUILD_ID=YOUR_GUILD_ID_OPTIONAL
   ```
4. Start the bot:
   ```bash
   npm start
   ```

## Railway

Set the same environment variables in Railway:
- TOKEN
- CLIENT_ID
- GUILD_ID

## Notes

- Do not upload your `.env` file to GitHub.
- Reset your token if it was ever shared publicly.
